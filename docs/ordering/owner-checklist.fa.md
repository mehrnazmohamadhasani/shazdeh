# چک‌لیست شازده قبل از شروع سفارش آنلاین

مواردی که ⛔ دارند باید **قبل از روشن کردن سفارش آنلاین** آماده باشند. بقیه را می‌شود بعداً تکمیل کرد.

## ۱. مدارک و اطلاعات کسب‌وکار
- [ ] اسم رسمی کسب‌وکار، دقیقاً مثل لایسنس ⛔
- [ ] کپی لایسنس تجاری و شماره‌ی آن ⛔
- [ ] تأیید DET که لایسنس شما اجازه‌ی فروش آنلاین و ارسال غذا را می‌دهد ⛔
- [ ] آدرس و لوکیشن آشپزخانه
- [ ] وضعیت ثبت مالیات بر ارزش افزوده (VAT) و شماره‌ی TRN ⛔
- [ ] شماره تلفن، واتس‌اپ و ایمیل برای تماس مشتری‌ها ⛔
- [ ] ساعت کاری و ساعت ارسال (با ساعت‌های رمضان و تعطیلات)

## ۲. منو
- [ ] منوی کامل آنلاین: دسته‌ها، اسم غذاها (انگلیسی و فارسی)، توضیح و قیمت ⛔
- [ ] غذاهایی که آنلاین فروخته **نمی‌شوند**
- [ ] اندازه‌ی پرس‌ها (کوچک/بزرگ و غیره)
- [ ] **مواد اولیه و آلرژن‌های هر غذا** ⛔
- [ ] گیاهی بودن و تند بودن هر غذا
- [ ] آپشن‌ها و افزودنی‌ها با قیمت (مثلاً نوع برنج، ته‌دیگ)
- [ ] قیمت‌ها با VAT است یا بدون آن؟
- [ ] عکس برای غذاهایی که عکس ندارند
- [ ] چه کسی غذاهای تمام‌شده را در سایت «ناموجود» می‌زند؟

## ۳. ارسال (Careem)
- [ ] تأیید اینکه ارسال فقط با Careem انجام می‌شود ⛔
- [ ] حساب Careem برای ثبت پیک (و اینکه چه کسی پیک را ثبت می‌کند)
- [ ] مناطق ارسال، و برای هر منطقه: **هزینه‌ی ارسال، حداقل سفارش، زمان تقریبی** ⛔
- [ ] حداکثر فاصله از آشپزخانه (طبق قانون شهرداری حدود ۳۰ دقیقه در راه)
- [ ] بسته‌بندی: چسب پلمپ، جعبه‌ی عایق، قاشق‌چنگال

## ۴. پرداخت
- [ ] روش‌های پرداخت: نقد هنگام تحویل / کارت هنگام تحویل / آنلاین ⛔
- [ ] اگر پرداخت آنلاین می‌خواهید: کدام درگاه؟ (Stripe، Telr، N-Genius و...)
- [ ] حساب بانکی برای واریز پول
- [ ] چه کسی پول را برمی‌گرداند (Refund)؟

## ۵. قوانین سایت
متن این‌ها را ما نوشته‌ایم؛ فقط باید شما و وکیلتان تأیید کنید:
- [ ] شرایط سفارش، حریم خصوصی، لغو و برگشت پول، شرایط ارسال
- [ ] نسخه‌ی عربی همه‌ی این متن‌ها ⛔

## ۶. کار روزانه‌ی آشپزخانه
- [ ] سفارش‌های جدید روی کدام دستگاه می‌آید؟ (لپ‌تاپ یا تبلت آشپزخانه) ⛔
- [ ] چه کسی سفارش را می‌بیند، پیک Careem می‌گیرد و وضعیت را عوض می‌کند؟
- [ ] شماره‌های واتس‌اپ برای اعلان سفارش جدید
- [ ] ایمیل برای اعلان سفارش جدید
- [ ] پرینتر سفارش لازم است؟ (پرینتر فیش ۸۰ میلی‌متری)
- [ ] اسم و ایمیل کارکنان برای ساخت حساب کاربری
- [ ] چه کسی جواب شکایت‌ها و لغو سفارش‌ها را می‌دهد؟
- [ ] وقتی آشپزخانه شلوغ است، چه کسی سفارش آنلاین را موقتاً متوقف می‌کند؟ (یک دکمه در پنل هست)

## ۷. برند
- [ ] فایل لوگو (ترجیحاً SVG)
- [ ] عکس‌های بیشتر از غذاها، اگر دارید
